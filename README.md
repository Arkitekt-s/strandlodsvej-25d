# Strandlodsvej 25D

En enkel, søgemaskinevenlig informationsside for lejligheden på Strandlodsvej 25D, 2. th., 2300 København S.

## Formål

Siden skal gøre adressen og boligens vigtigste oplysninger lettere at finde i Google og sende besøgende videre til den officielle salgsannonce hos home.dk.

## Publicering

Siden er lavet til GitHub Pages og kan publiceres fra `main`-branchens root-mappe.
